# Ahmed Taha - Personal Portfolio 👨‍💻✨

> **Clean, Modern, and Fully Responsive Trilingual Portfolio Website**

A personal developer portfolio built with Vanilla HTML5, CSS3, and modern JavaScript, featuring instant **Dark / Light mode** toggling and full **trilingual support** for **English (EN)**, **Afaan Oromoo (OM)**, and **Amharic (አማ)**.

🌐 **GitHub Repository**: [https://github.com/ahmed-teha/portfolio](https://github.com/ahmed-teha/portfolio)

---

## ✨ Features

- **🎨 Modern Design & Glassmorphism**: Clean dark-mode aesthetic with refined violet/cyan gradient accents, responsive typography, and glowing hover micro-interactions.
- **🌍 Trilingual Internationalization (i18n)**:
  - **English (EN)**
  - **Afaan Oromoo (OM)**
  - **Amharic (አማ)** with crisp Ethiopic script typography (**Noto Sans Ethiopic**).
  - Remembers selected language using `localStorage`.
- **🌓 Seamless Theme Switcher**: Toggle between calibrated Dark Mode and crisp Light Mode with persistent user preferences.
- **⌨️ Dynamic Hero Typewriter**: Automatically types out engineering roles in the active language.
- **📱 Fully Responsive**: Fluid, mobile-first design with an animated collapsible hamburger drawer.
- **⚡ Interactive Contact Form**: Real-time client-side input validation with success toast notifications.
- **📬 Reliable Contact Channels**:
  - One-click **Copy Email** button with instant clipboard feedback.
  - Direct **Open in Gmail** webmail compose link.
  - Direct links to **Telegram** (`@beyondimaginer32`) and **GitHub** (`@ahmed-teha`).
